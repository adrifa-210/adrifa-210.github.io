Ejercicio 18. La palabra más larga de una frase

split() + bucle for para recorrer las palabras

← Volver al índice

Enunciado

Escribe una función que encuentre la palabra más larga en una frase ingresada por el usuario.

  • Usa split() para dividir la frase en palabras.
  • Recorre el array con un bucle for para encontrar la más larga.
  • Compara con .length de cada palabra y guarda la máxima.

Elementos del ejercicio

Resultado

Frase cargada. Pulsa el botón para buscar la palabra más larga.
