Fundamentos de JavaScript

DWECL • Práctica 1.1: Arquitecturas y lenguajes de programación en clientes web

Colección completa de los 21 ejercicios solicitados en el anexo de la práctica.

Ejercicio 1

Variables y tipos de datos en la consola

Declara variables de varios tipos. Muestra el contenido en la consola junto con el tipo de dato. En este ejercicio utiliza el console.log, console.error, console.info y el console.debug

 Ejercicio 2

Array de 100 números y filtrado

Declara un array de 100 números. Rellena el array con valores al azar. Muestra el contenido console.table. Realiza un filtrado de datos. Por ejemplo mostrando los valores de un determinado rango

 Ejercicio 3

Objeto Persona y console.table

Declara un objeto persona con las propiedades más habituales, usando todos los tipos de datos incluidos un array y otro objeto. Muestra el contenido usando console.log y console.table

 Ejercicio 4

Suma con prompt() y Number()

Escribe un programa que pida al usuario ingresar dos números y luego muestre la suma. Usa prompt() para pedir datos al usuario y Number() para convertir las entradas a números. Usa console.log() para mostrar el resultado

 Ejercicio 5

Número par o impar

Crea un programa que verifique si un número ingresado por el usuario es par o impar.

 Ejercicio 6

Número par o impar desde input

Crea un programa anterior para que se obtenga el número de un campo input.

 Ejercicio 7

Contar vocales en una palabra

Contar vocales en una palabra. Escribe una función que reciba una palabra y cuente cuántas vocales tiene. Usa un bucle for y la función includes() para verificar si un carácter es una vocal.

 Ejercicio 8

Número aleatorio en un intervalo

Escribe una función que permita generar un número aleatorio entero entre un intervalo. Por ejemplo azar(-5, 10). Salida: 3

 Ejercicio 9

Revertir una cadena

Revertir una cadena. Escribe una función que tome una cadena como argumento y devuelva la cadena invertida. Usa el método split() para convertir la cadena en un arreglo, reverse() para invertir el arreglo, y join() para unirlo de nuevo.

 Ejercicio 10

Número más grande en un array

Encontrar el número más grande en un array. Crea una función que encuentre el número más grande en un array. Usa el método Math.max() y el operador ... para "expandir" el array

 Ejercicio 11

100 números del 1 al 20 y frecuencias

Escribe un programa que genere 100 números del 1 al 20. Debe mostrar la cuenta de los números que al menos han aparecido una vez.

 Ejercicio 12

Filtrar números pares de un array

Filtrar números pares de un array. Crea una función que tome un array de números y devuelva un nuevo array con solo los números pares. Usa filter() y el operador %

 Ejercicio 13

Contar palabras en una frase

Contar palabras en una frase. Escribe un programa que cuente cuántas palabras tiene una frase ingresada por el usuario. Usa el método split() para dividir la frase en un array de palabras.

 Ejercicio 14

Verificar si una palabra es palíndromo

Verificar si una palabra es un palíndromo. Escribe una función que verifique si una palabra es un palíndromo (es decir, si se lee igual al derecho y al revés). Compara la palabra original con su versión invertida usando split(), reverse() y join().

 Ejercicio 15

Números primos en un rango

Encontrar los números primos en un rango. Escribe un programa que imprima todos los números primos entre 1 y un número dado por el usuario. Crea un función llamada esPrimo(num) que reciba num, un número entero

 Ejercicio 16

Grados Celsius a Fahrenheit

Convertir grados Celsius a Fahrenheit. Escribe una función que convierta grados Celsius a Fahrenheit. La fórmula es: Fahrenheit = (Celsius * 9/5) + 32

 Ejercicio 17

Ordenar un array de números

Ordenar un array de números. Escribe un programa que tome un array de números y lo ordene de menor a mayor. Usa el método sort() con una función de comparación.

 Ejercicio 18

Palabra más larga en una frase

Encontrar la palabra más larga en una frase. Escribe una función que encuentre la palabra más larga en una frase ingresada por el usuario. Usa split() para dividir la frase en palabras, luego recorre el array con un bucle para encontrar la palabra más larga.

 Ejercicio 19

Calcular el promedio con reduce()

Calcular el promedio de un array de números. Escribe una función que reciba un array de números y calcule su promedio. Usa reduce() para sumar todos los números y luego divide entre la longitud del array.

 Ejercicio 20

Mayúsculas y minúsculas

Convertir una cadena a mayúsculas y minúsculas. Escribe una función que convierta una cadena de texto a mayúsculas y luego a minúsculas, mostrando ambos resultados. Usa los métodos toUpperCase() y toLowerCase().

 Ejercicio 21

Filtrar números mayores que un valor

Filtrar números mayores que un valor. Escribe una función que tome un array de números y un valor, y devuelva un nuevo array con los números que son mayores que ese valor. Usa filter() para crear el nuevo array.
