Ejercicio 1: Variables y tipos de datos en la consola

Declaración de variables y métodos de console

Enunciado

Declara variables de varios tipos. Muestra el contenido en la consola junto con el tipo de dato. En este ejercicio utiliza el console.log, console.error, console.info y el console.debug

Resultado

Presiona el botón para mostrar los datos en la consola y en pantalla.
