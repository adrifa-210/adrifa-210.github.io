Ejercicio 9: Revertir una cadena

Manipulación de cadenas con split, reverse y join

Enunciado

Revertir una cadena. Escribe una función que tome una cadena como argumento y devuelva la cadena invertida. Usa el método split() para convertir la cadena en un arreglo, reverse() para invertir el arreglo, y join() para unirlo de nuevo.

Resultado

Presiona el botón para invertir el texto.
